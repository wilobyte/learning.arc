## Concepts and Definitions  
-  `cp` copies files and directories has options and an argument then destination
- `mv` is used to move and rename files
- `mkdir` is used to create directories, you can make multiple at once
- Using wildcards is cool for getting stuff done in the terminal basically it's just for selecting files that match a specific pattern.
- Essentially there's classes, sets and whatnot. Life [!characters], [characters]. classes: [:alnum:], [:alpha:], [:digit:], [:upper:], [:lower:] and `*` for any amount of characters, `?` for any single character.
- So for links, basically they point to a single file in the case of hard links it simply assigns a new directory listing for it the contents still exist after the file has been deleted and you cant link directories, for soft links, it basically just creates a text pointer to the file you desire if you delete a link, the file still exists, if you delete the file, the links become broken.
- All files are linked to a name by default.
- So basically what hard links do is just assign new names to the data part of a file so the original file and the hard link share the same inode number which is what the system assigns to files.
- Symbolic links work with devices outside the filesystem, with folders

## Concepts and Definitions  
-  If you glance through the raw $\LaTeX$ file, you will see various extra words preceded by the "backslash character"(`\`) such as `\begin{equation}` and `\end{equation}`, and special characters like `$, ^,` and `_`. These tell $\LaTeX$ how to format the document.
- Also notice the lines:
	``` latex
	\documentclass{article} 
	\begin{document}
	```
	at the beginning of the file and
	`\end{document}`
	at the end.
	- Lines like these must appear in every $\LaTeX$ document; their use will be discussed later.
	- The rest of the examples from the book are small chunks of $\LaTeX$ in a complete document, and hence won't include these commands.
- Extra commands are sometimes placed between `\documentclass` and `\begin{document}`; this part of the document is called the *preamble*.
- $\LaTeX$ generally regards groups of characters separated by spaces as words.
- A "newline" generated by the Return (or Enter) key is also thought of as a space.
- The number of spaces between words is immaterial. The output will remain the same if I put 1 or 100.
- A "newline" character is treated as an inter-word space, it doesn't matter where newlines occur in a file, $\LaTeX$ will make up it's mind on how to arrange the lines in the paragraph often hyphenating words where necessary to produce a clean output.
- A blank line or a number of blank lines signify the ending of a paragraph. Use blank lines often as they make your `tex` file easier to read.
- A paragraph is automatically indented unless it's the first in a section. You can override this with the `\noindent` command at the start of a new paragraph.
- The following characters have a special meaning in $\LaTeX$:
	`\ & $ % ~ _ { } # ^`
- When you want one of these characters to appear in the output, most of them are generated by preceding the character with a backslash.
	```latex
	\& \$ \% \_ \{ \} \#
	```
	$\&, \$, \%, \_, \{, \}, \#$
- If a % sign is included in a line without being preceded by a backslash the rest of the line will disappear. For example:
	```latex
	h\%backslide
	```
	output: $$h\%backslide$$
	
	```latex
	h%backslide
	```
	output: $$
h % backslide
$$
- `\verb` can also display special characters (and ordinary characters too) in a typewriter form. For example:
	`\verb"%~and\"` produces %~and\.
	- The character immediately following verb (") acts as the opening delimeter--everything will be printed out "verbatim" up to next the occurrence of that character. 
	- The text between delimeters should not be broken across lines in the source file.
	- For the above reason, `verb` is only suitable for short bursts of verbatim input.
- ### Type Style
	- For variation and emphasis, the style of the type can be altered.
	- You can control the shape, series and family of the type.
	- We have for shapes
		```latex
		\textup{Upright type}
		\textit{Italic type} 
		\textsl{Slanted type}
		\textsc{Small caps type}
		```
	- and two series
		```latex
		\textmd{Medium}
		\textbf{Boldface}
		```
	- and three families
		```latex
		\textrm{Roman}
		\textsf{Sans serif}
		\texttt{typewriter}
		```
	- Note that the text whose type is to be changed is enclosed in curly brackets after the command. 
	- You can combine all three features.
	- `emph` is used as a command to emphasize text in the brackets placed after the command. It's usage is `\emph{text}`. The emphasis also depends on the type style currently in use; `\textsc{\emph{text}}` would produce a different effect when compared to `\textit{\emph{text}}`.
	- The declarations: 
		```latex
		\Huge \huge \LARGE \large \normalsize \small \footnotesize \scriptsize \tiny
		```
		can be used to change text size selectively. 
	- Usage: `{\LARGE LARGE text}`, `{\tiny tiny text}`
	- If the particular combination of shape, series, family and size is not available on your system, $\LaTeX$ will warn you and substitute a "nearby" alternative.
- ### Environments
	- Environments are portions of the document that we want $\LaTeX$ to treat differently from the main body.
	- They are generally created by enclosing text in-between the following commands:
		```latex
		\begin{environment name}
		...
		\end{environment name}
		```
	 - Below I'll highlight some important ones:
		 - #### Lists
			 - There are several list environments. The `itemize` version produces bullets.
			 - Example:
				 ```latex
				 \begin{itemize}
					 \item this is an item
					 \item here's another
				\end{itemize}
				```
			 - Numbered lists use `enumerate`. 
			 - Example:
				```latex
				 \begin{enumerate}
					 \item this is an item
					 \item here's another
				\end{enumerate}
				```
			 - The `description` environment accepts an optional argument enclosed in square braces after the `item` command. 
			 - The argument can be used to customize the headings.
			 - The optional argument is set in a bold typeface.
			 - Example:
				 ```latex
				 \begin{description}
					 \item[Rule 1.] Thou shalt learn latex
					 \item[Rule 2.] Thou shalt use latex as a flex
				\end{description}
				  ```
			- List can also be nested.
			- Example:
				```latex
				\begin{enumerate}
					\item{nest}
						\begin{enumerate}
							\item{chirp chirp}
						\end{enumerate}
				\end{enumerate}
				```
		- #### Centering
			- The `center` environment places text in the center of the line. (just like regular left, right, center adjustments)
			- The `\\` command signals the end of a line.
			- Example:			  
				```latex
				\begin{center}
					{\large{\textbf{\textit{Freaky} Assignment}}}\\
					Wil Fredrick\\
					LX101
				\end{center}
				wsg bbg
				```
		- #### Tables
			- There are two environments related to tables;
			- `tabular` produces the table. 
			- `table` is used to give the table a caption and a possible key for cross referencing. 
			- The form of the `tabular` environment is:
				```latex
				\begin{tabular}{format}
				...
				\end{tabular}
				```
			- The `format` tells $\LaTeX$ how many columns there should be and how they should be; left justified (l), centered (c) or right justified (r).
			- Example usage of `tabular`:
				```latex
				The table below contains the people with the most aura in the faculty.
		
				\begin{tabular}{lrc}
					Name & Mat No. & Dept. \\
					\hline
					Ochala Wilfred & ENG2204195 & STE 
				\end{tabular}

				As we can see, his aura is superior throughout heaven and earth.
			   ```
			- From the snippet above we can see `{lrc}` made the first column left justified, the second right justified, and the third centered. 
			- The entries across each row on the table are separated by `&`.
			- Each line except the last terminates with `\\`.
			- A horizontal line was created by placing `\hline` after the `\\`.
			- Blank line precede and follow the `tabular` environment so it exists as it's own paragraph (otherwise the table would be formatted as part of the surrounding text.)
			- The table is left justified on the page.
			- Vertical lines can be drawn by including `|` at the appropriate points in the format specification. 
			- Here's an example; you can center the table as well:
				```latex
				\begin{center}
					\begin{tabular}{|l||r||c|}
						\hline
						Name & Mat No. & Dept. \\
						\hline \hline
						Wilfred Ochala & ENG2204195 & STE\\
						\hline
					\end{tabular}
				\end{center}
						
				```
			- In order to have entries span more than one column of a table we use `\multicolumn`.
			- Here's an example:
				```latex
				\begin{tabular}{|l||r||r|}
					\hline
					& \multicolumn{2}{c|}{Marks}\\
						\cline{2-3}
					Name           & MEE351& MEE361\\
					\hline \hline
					Ochala Wilfred & 100 & 100\\
					\hline
				\end{tabular}
					
				```
			- The `multicolumn` command has three arguments;
			- The first specifies how many columns it should span,
			- the second whether to justify left, right or to center the entry(`|` is included to make sure the border of the surrounding box is complete.),
			- and the third contains the content
			- `cline{2-3}` draws a horizontal line through columns 2 to 3.
			- For a line spanning a single column, use `cline{2-2}` for example.
			- The `&` before the `\multicolumn` command is used to remove the "Name" column from the part to be multi "columned" by "Marks" i.e MEE351 and MEE361. 
			- If I wanted the "Marks" column to span over MEE361 only I can write something like:
				```latex
				...
				& & \multicolumn{1}{c|}{Marks}
					\cline{3-3}
				...
				```
			- Next we place the table in the `table` environment and give it a caption and a key.
			- By designating a key after the caption with `\label{mytable}`, we can refer to this table anywhere in the document by `\ref{mytable}`, at which point the table will be automatically inserted.
			- Here's an example:
				```latex
				\begin{table}
					\begin{center}
						\begin{tabular}{lrc}\hline 
							Name & Mat No. & Dept. \\ 
							\hline Ochala Wilfred & ENG2204195 & STE\\
							\hline 
						\end{tabular}
						\caption{Aura Farmers}\label{tab:a}
					\end{center}
				\end{table}
				
				\ref{tab:a} shows that the person above is the top aura farmer currently in the faculty.
				```
			- The `table` environment is a "floating environment" that is normally placed in the output document roughly where it is input.
			- Sometimes $\LaTeX$ is not able to fit them neatly onto the current page so they are permitted to float to a more convenient location.
			- An optional argument can be added to `\begin{table}`. 
			- Specifying `\begin{table}[h]` tells $\LaTeX$ to that you wish the table to appear here (where it has been typed in);
			- other options are [t] for the top of the page, [b], for the bottom of the page, and [p], which puts the table on a separate page containing other "floating bodies".
			- It is possible to include more than one location specifier i.e `\begin{table}[tbh]` which tells $\LaTeX$ that our preferences are `t`, `h`, `b` in that order.
			- Sometimes preferences might be overridden, so you can use preface the location specifier with a "!" i.e `[!t]` for example to insist $\LaTeX$ places the table at the top of the page.
		- #### Verbatim
			- Useful for displaying sections of computer code, raw $\LaTeX$, etc., since it prints out text exactly as it was input and uses a (nonproportionally spaced) typewriter font. 
			- The special characters `\&%~_{}#^` lose their $\LaTeX$ significance within this environment.
			- Example:
				```latex
				\begin{verbatim}
				[wilobyte@wilobyte-pc latex]$ ls
				tests.aux  tests.dvi  tests.log  tests.tex
				name = 5, 8
				for name in names:
					print(name*5)
				\end{verbatim}
				```
			- A similar command `\verb` is more appropriate for shorter bursts of verbatim output.
		- #### Vertical and Horizontal Spacing
			- The vertical spacing between lines can be altered using `\bigskip`, `\medskip` and `\smallskip`. 
			- Consider the example below:
				```latex
				\begin{center}
					{\large{\textbf{\textit{Freaky} Assignment}}}\\
					\medskip
					
					Wil Fredrick\\
					\smallskip
					
					LX101
				\end{center}
				\bigskip
				
				wsg bbg
			  ```
			- When one of these commands occurs in the middle of a paragraph, the space is added at the end of the next complete(formatted line), which is why they have been preceded by blank lines in the preceding example.
			- The precise spacing caused by the three `skip` commands depends on certain style parameters that will be discussed later.
			- Absolute vertical spacing can be achieved with `\vspace`.
			- The command `\vspace{2.2in}` will leave a vertical space of 2.2 inches.
			- You can use other units of length like `mm`(millimeters), `em`(the width of the letter "M"--the widest character), `ex`(the height of the letter "x"), and `pt` for points.
			- Negative lengths are permitted; `\vspace{-0.25in}` will move the character following it 0.25 inches.
			- The command `\fill` represents an infinitely stretchable length.
			- So for example `\vspace{\fill}` will produce a vertical gap that extends to the foot of the page (unless this `\fill` is competing with another infinitely stretchable `\fill`).
			- Horizontal spacing works in the same way with the `\hspace` command.
			- Example:
				```latex
				Measure this with a ruler.
				\vspace{0.2in}

				Push right\hspace{1in}one inch.

				Left\vspace{\fill}Middle\vspace{\fill}Right
				```

## Code Snippets  
``` latex
\documentclass{article}

\begin{document}

This is a short document to illustrate the basic use of \LaTeX.

Simply leave a blank line to get a new paragraph; indentation is automatic.

Mathematical expressions such as $y = 3 \sin x$ are obtained with dollar signs. Equations can be displayed, as in
\[
	y = 3 \sin x.
\]
Numbered equations are also possible:
\begin{equation}\label{equa}
	y = 3 \sin x.
\end{equation}
Because we have labeled this equation we can refer to it without having to know its number (\ref{equa}).

Powers (superscripts), as in $x^2$, are obtained with the \verb"^"; more complicated powers must live in curly braces: $x^{2+\alpha}$.

Likewise, subscripts are obtained with the underscore: $y_3$ or $y_{n+1}$.

We can get both with $x_{n+1}^{2+\alpha}$.

\end{document} ```
